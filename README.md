**DebrisShield**

Satellite & Space Debris Collision Predictor

**Overview**

DebrisShield is a web-based simulation that analyzes potential collision risks between satellites and space debris. It combines backend calculations with real-time visualizations like orbit simulation and distance graphs.

** Features**
-Collision risk calculation (distance, velocity, probability)
-Live distance graph (Satellite vs Debris)
-Orbit simulation using canvas
-Interactive controls (pause/play, speed)
-Animated space background

**Tech Stack**
**Frontend:** HTML, CSS, JavaScript (Canvas)
**Backend:** Python (Flask)
