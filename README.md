**Space-Themed Portfolio Website**

This is a personal portfolio website built using HTML, CSS, and JavaScript, designed with a modern space-inspired purple theme.

The website presents a structured overview of profile, interests, and work in a clean and visually engaging layout.

 **Features**
-Space-themed UI with purple gradient and blurred planet background
-Typing animation in the hero section
-Smooth scrolling navigation
-Minimal and clean section-based layout
-Responsive and user-friendly design

 **Sections Included**
 
**Home** – Introduction with typing effect

**About** – Brief personal overview and interests in space technology

**Skills** – Technologies and tools

**Projects** – Key work and ideas

**Contact **– Basic contact information

**Technologies Used**

**HTML5** – Structure

**CSS3** – Styling (glassmorphism + gradients + animations)

**JavaScript** – Interactivity (typing effect, smooth scroll)

**Purpose**

The goal of this project is to create a simple, clean, and visually appealing portfolio while learning frontend development and UI design.

**Note**

This project focuses on design, layout, and basic interactivity. It can be further enhanced with advanced animations, backend integration, or deployment.
